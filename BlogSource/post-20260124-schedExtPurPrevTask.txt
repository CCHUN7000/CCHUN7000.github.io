# Analyzing sched_ext Put Previous Task Logic in Linux Kernel

Date: 24/1/2026
Author: Chunbo

## Introduction
When the running task is leaving CPU, put_prev_task_scx is used to put this
task back to the running queue.

## Key Function -- put_prev_task_scx
In the beginning, update_curr_scx is called to refresh the slice of this running queue.
Afterthat, if stopping logic of SCX is defined, and there exists a queued task, call it.

```c
static void put_prev_task_scx(struct rq *rq, struct task_struct *p,
			      struct task_struct *next)
{
	struct scx_sched *sch = scx_root;
	update_curr_scx(rq);

	/* see dequeue_task_scx() on why we skip when !QUEUED */
	if (SCX_HAS_OP(sch, stopping) && (p->scx.flags & SCX_TASK_QUEUED))
		SCX_CALL_OP_TASK(sch, SCX_KF_REST, stopping, rq, p, true);
```

When there exists a new queued task:
1. Set the current task p as runnable.
2. If p still has slice, and we are entering a scheduler class with higher priority, 
put p at the head of local running queue.
3. If we are entering a scheduler class with lower priority, 
but p is still runnable now,
this might be a problem, and we use do_enqueue_task with SCX_ENQ_LAST
to trigger an explicit follow-up scheduling.
4. Otherwise, just simplely put p at the end of the queue.
```c
	if (p->scx.flags & SCX_TASK_QUEUED) {
		set_task_runnable(rq, p);

		/*
		 * If @p has slice left and is being put, @p is getting
		 * preempted by a higher priority scheduler class or core-sched
		 * forcing a different task. Leave it at the head of the local
		 * DSQ.
		 */
		if (p->scx.slice && !scx_rq_bypassing(rq)) {
			dispatch_enqueue(sch, &rq->scx.local_dsq, p,
					 SCX_ENQ_HEAD);
			goto switch_class;
		}

		/*
		 * If @p is runnable but we're about to enter a lower
		 * sched_class, %SCX_OPS_ENQ_LAST must be set. Tell
		 * ops.enqueue() that @p is the only one available for this cpu,
		 * which should trigger an explicit follow-up scheduling event.
		 */
		if (sched_class_above(&ext_sched_class, next->sched_class)) {
			WARN_ON_ONCE(!(sch->ops.flags & SCX_OPS_ENQ_LAST));
			do_enqueue_task(rq, p, SCX_ENQ_LAST, -1);
		} else {
			do_enqueue_task(rq, p, 0, -1);
		}
	}

switch_class:
	if (next && next->sched_class != &ext_sched_class)
		switch_class(rq, next);
}
```
