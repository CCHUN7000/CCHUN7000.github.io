Analyzing sched_ext Scheduler

With the development of eBPF technologies, the sched_ext scheduler framework has emerged as a powerful tool for customizing Linux kernel scheduling. This project aims to provide a comprehensive analysis for developers (myself) interested in understanding, utilizing, and optimizing the sched_ext scheduler.

Framework Introduction

sched_ext is an extension tool for linux kernel without modifying the code. It is used to customize the scheduling policy for different workloads. Now we can see there are many useful examples, and even some experimental designs based on astrology or gambling.
