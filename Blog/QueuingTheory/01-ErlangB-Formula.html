Queueing Theory 2026-04-12

Erlang B & Erlang C

Foundation of queueing theory: blocking probability, waiting time, and capacity planning.

M/M/c System Classification

Erlang C — Waiting System

  • All arrivals wait until served
  • Infinite queue capacity
  • New customer never rejected
  • Calculates: waiting probability

Use: CPU scheduling, bank queues

Erlang B — Loss System

  • Arrivals blocked when all servers busy
  • Queue capacity = 0
  • New customer immediately rejected
  • Calculates: blocking probability

Use: phone lines, connection pools

Parameters

c = number of servers
λ = arrival rate (tasks/sec)
μ = service rate (tasks/sec per server)
ρ = λ/(c·μ) = utilization
1/μ = avg service time
A = λ/μ = traffic intensity (Erlangs)

Note: ρ must be < 1 for system stability (Erlang C)

Erlang C — Waiting Probability

Probability that an arriving customer must wait (all servers busy):

ErlangC(c, ρ) = (cρ)^c / c! / (cρ)^c / c! + (1-ρ) · Σ(n=0 to c-1) (cρ)^n / n!
// Recursive form (numerically stable)
C(c, ρ) = (c·ρ) / (c - ρ·(1 - C(c-1, ρ)))
C(1, ρ) = ρ

Erlang C — Wait Time

Wq = ErlangC(c, ρ) / (c · μ · (1 - ρ))
// Average wait time in queue
W = Wq + 1/μ
// Average time in system
Lq = λ · Wq
// Average number in queue
L = λ · W
// Average number in system

Erlang B — Blocking Probability

Probability that all c servers are busy (customer is blocked):

ErlangB(c, ρ) = (cρ)^c / c! / Σ(n=0 to c) (cρ)^n / n!
// Recursive form (recommended for computation)
B(c, ρ) = ρ / (ρ + (c - ρ) · B(c-1, ρ))
B(0, ρ) = 1

Erlang B — Effective Throughput

λeff = λ × (1 - ErlangB(c, ρ))
// Effective throughput (blocked customers rejected)
ρeff = ρ × (1 - ErlangB(c, ρ))
// Effective utilization

Example: Call Center

10 agents, avg call 3 min (μ=20/hr), λ=100 calls/hr

Erlang C (calls wait in queue)

ρ = 100/(10×20) = 0.5

C(10, 0.5) ≈ 0.021

Wq = 0.021 / (10×20×0.5) = 0.00021 hr

≈ 0.75 seconds wait

Erlang B (calls rejected)

B(10, 0.5) ≈ 0.001

0.1% blocked

λeff = 100 × 0.999 ≈ 99.9

Application: CPU Scheduling

Erlang C — Batch Processing

Tasks queue when cores busy. Calculate wait time Wq for non-real-time workloads.

Erlang B — Real-Time Tasks

Tasks rejected when cores saturated. Calculate blocking probability for RT tasks.

Summary

Erlang C

Wq = ErlangC / (cμ(1-ρ))

Waiting systems

Erlang B

B = (cρ)^c/c! / Σ(n=0 to c)(cρ)^n/n!

Loss systems

  • Traffic: A = λ/μ (Erlangs)
  • Utilization: ρ = λ/(cμ), must be < 1 for Erlang C stability
